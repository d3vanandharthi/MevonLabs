MEVON LABS — REGENERATED LUXURY WEBSITE

WHAT YOU HAVE
16 HTML pages, original SVG material studies, native WebGL models, interactive project selector, material-study dialogs, inquiry composer, SEO metadata, structured data, sitemap and hosting configuration. This is a fresh regeneration of the design, not a byte-identical recovery of the earlier ZIP. No CMS, backend, payment system or analytics is included. The website has not been deployed.

OPEN THE PREVIEW
The separate HTML preview is self-contained: save/open it in a modern browser. Attachment viewers may restrict scripts; the saved HTML itself includes the scripts. Preview links navigate to homepage sections; full internal pages are in the ZIP.

OPEN THE COMPLETE SITE
Extract the ZIP, open the mevonlabs folder and open index.html. For a local server, run python -m http.server 8000 inside that folder and visit localhost:8000. No Node installation or build is needed.

3D AND INTERACTION
Switch ceramic art / decals / engraved stone; drag or use arrow keys to rotate. Pause is available. Models are procedural illustrations, not actual products or customer commissions. Animation pauses when offscreen or when the page is hidden. Reduced-motion settings disable automatic rotation. A material illustration remains when WebGL is unavailable. Real browser and device testing is still required.

CONTACT
The form prepares a WhatsApp draft for the selected brand. It does not save or submit data to the website or send an email. The visitor reviews the draft and presses Send inside WhatsApp. The project selector saves no personal data.

HOSTING
Back up an existing site first. Upload the CONTENTS of the website folder to the domain document root, not a nested mevonlabs folder. Include HTML pages, assets, robots.txt, sitemap.xml and .htaccess for Apache hosting. Netlify and Cloudflare Pages configurations are also supplied; no build command is needed. Keep README.txt and QA-REPORT.json off the public server unless intentionally public.
Use the actual provider DNS records and preserve existing mail MX/TXT records. Enable HTTPS; choose https://mevonlabs.com as primary and configure HTTP/www redirects at the host. Verify there are no redirect loops and nonexistent URLs return a real 404.

BEFORE LAUNCH
Confirm company wording, all services, phone numbers and address with the owner. Add real licensed product photography. Do not label illustrative models as actual products. Confirm the legal entity and privacy contact and the host logging/retention practices. Review the privacy notice before publication. Confirm current prices, timings, shipping and installation directly with the brands. Keep ceramic finished-piece testing qualifications.
Test all controls in a current desktop browser and on phones: menu, 3D, pause, keyboard controls, material dialog, selector and WhatsApp routes. JavaScript syntax and static source checks are not rendered-browser tests.

Add natural parent-company links from the existing brand sites with owner approval. Indexing, rich results and rankings are not guaranteed or verified.
